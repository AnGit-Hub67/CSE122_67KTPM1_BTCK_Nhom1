## Integration dependencies and limits

This is frontend/demo access control, **not server-side security**. Session values and localStorage can be edited by the user. Data is shared only on the same browser origin/profile; it is not a multi-device database. Real deployment needs server authentication, per-operation authorization, persistence and a privacy design.

1. SV1 login already uses the same `campusmind.session.v1` contract in the local reference. On integration, reconcile the shared header with SV1 login to avoid duplicate account links. The old student-only session key is ignored and cleared on explicit login/logout. The standalone SV2 login can then be consolidated with SV1 login after integration tests.
2. Counselor contract remains `campusmind.counselor.v1` containing slots/appointments/notes/activity; `counselorId` and `studentId` support ownership, with legacy counselor mapping retained. Existing stored schedules, including empty slots, remain authoritative and are never silently replaced by mock availability. Both sides must agree on origin, slot IDs, availability, statuses and write locking.
3. The branch does **not** include SV3 counselor queue/schedule/note pages. The two actual SV3 UI round trips in the smoke suite are explicitly skipped. A shared-store fixture verifies Confirmed rendering, but is not evidence of complete SV3 UI integration. Retest Counselor confirmation and completion after combining branches. This patch does not let students confirm their own appointments.
4. TASK-18 is a local deterministic mock, not a live AI service; its route targets resolve and saved suggestions are scoped to the current student. It does not provide clinical advice.
5. Visitor profile weekly schedules and the service-duration discrepancy (60-minute service versus 50-minute slot) remain SV1/SV3 coordination items. Booking uses actual slot start/end from the shared store; no invented break-time explanation or global duration change was added. UI-kit/footer/homepage editorial changes are outside this SV2 patch.
